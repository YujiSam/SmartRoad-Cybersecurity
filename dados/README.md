# Dados

Todos os dados do projeto são **simulados**:

- **CPFs:** gerados por `gerar_cpfs_ficticios.py` (dígito verificador válido, mas não pertencem a ninguém).
  O CPF `529.982.247-25` usado nas rotas de demo é um CPF fictício comumente usado em testes.
- **Grafo do bairro:** 10 pontos e 12 trechos inventados em `app/grafo.py`.
- **Relatos:** criados pelos scripts de demonstração.

Nenhum dado pessoal real é coletado, armazenado ou enviado a terceiros (nem à LLM).
